Fearless Wallet is a browser extension for creating crypto accounts, viewing balances and transaction history, and connecting to compatible decentralized apps. You review requests before approving them. Available features depend on the selected network and account.

This security update limits existing local wallets to recovery actions: backup export, supported transfers out, unstaking, withdrawals and claims. Deposits, swaps, new staking and other normal use are blocked on those wallets. Create a fresh wallet in the updated extension, back up its recovery phrase, and move supported assets to its new addresses. Importing an old recovery phrase does not create new keys. Keep old backups until recovery is complete; network fees and unstaking waiting periods still apply.

Bitcoin support covers viewing addresses, balances and transaction history. Sending is not available.

SORA Nexus Taira testnet supports account balances, transaction history and connections to compatible decentralized apps, with signing approval for eligible new wallets. In-wallet asset transfers are unavailable, and mainnet is disabled by default.

You can export password-encrypted backups and optionally store them in your private Google Drive application-data folder. See the linked privacy notice for local storage, network requests, app permissions and backup details.

Help and supported features: https://fearlesswallet.io
