# Chrome Web Store metadata correction 3.0.8

Google rejected the 3.0.7 submission on 22 October 2026 under Yellow Argon
(keyword stuffing). The dashboard specifically quoted the six-network list
in the package short description. The correction removes that list from both
the package summary and the full listing. The underlying upgrade popup,
recovery restrictions, privacy notice and application behavior remain as
recorded in `docs/chrome-web-store-release-3.0.7.md`.

The package version is 3.0.8. Its short description and exact release-audit
expectation are:

> Manage crypto accounts, view balances, and connect to compatible decentralized apps.

The full listing uses ordinary feature sentences, retains the limited
Bitcoin and Taira capabilities, and describes recovery actions as supported
operations rather than guaranteeing recovery of every asset or position.
The privacy single-purpose statement describes the wallet purpose without
listing network brands or embedding a version number.

Google's guidance: <https://developer.chrome.com/docs/webstore/spam-faq#keyword-spam>.
The short summary is generated by `src/extension/makeManifest.cjs` from
`package.json`, so editing only the dashboard would leave the rejected text
in the uploaded package. The release audit continues to require the exact
reviewed summary; it does not relax the metadata validation.
