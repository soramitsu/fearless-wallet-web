---
question: How do I fix connection issues?
answer: If you encounter network issues while using Fearless Wallet, it may be due to network instability. A simple solution is usually available; please check our troubleshooting guide for more details.
---

Sometimes you may encounter network issues when using Fearless Wallet. This is a common situation that happens when a network is experiencing instability. But don't worry, there's a simple solution!

To fix this, you'll need to switch network nodes. Here's a step-by-step guide on how to do it: [How do I switch network nodes?](https://wiki.fearlesswallet.io/accounts/walkthrough/switching-network-nodes)

This guide will provide you with a comprehensive explanation of how to switch nodes and fix connection issues. Usually, simply switching to a different node can resolve the issue and get you back up and running!
