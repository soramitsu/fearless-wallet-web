We are happy to provide an update with more features from the early access version with several fixes for bugs discovered by a community:
• New feature - Receive screen
• New feature - Skip mnemonic confirmation
• Bug Fixes:
1. Improved error handling in Import account flow
2. Fixed issue during account creation related to Biometry, causing app to stuck on pin code flow
3. Fixed scrolling issue in Transfer history 
4. Fixed disconnects each minute from blockchain node
5. Fixed incorrect behavior for back button in the Import account flow
6. Added ability to Import account using seed with 0x prefix
7. Fixed Reserved balance part in Frozen balance
8. Updated title for My accounts on Send flow

...and minor UX/UI fixes
