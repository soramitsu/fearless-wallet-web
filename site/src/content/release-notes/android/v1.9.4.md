Wallet
- History now shows all records for the account: added support for staking rewards, slashes and other operations

Staking
- Improved & fixed "Total rewards" on Staking screen
- Fixed "Oversubscribed" Alert: now it shows only when user's stake is allocated to oversubscribed part
- Fix number of "Elected" validators: now displays correct amount
- Removed limitation to change staking parameters (e.g. validators) if maximum nominators in network reached

General
- Improved USD display: Migrated from Subscan API to Coingecko API
- Rewards rate is now optional in Crowdloans: for some crowdloans which have no information about rewards Fearless Wallet now won't display it
- Fixed Patract nodes URL
